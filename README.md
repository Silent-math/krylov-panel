# Krylov · tablero en vivo

Página estática que muestra cómo va el equipo en Platanus Hack 26. Lee, desde el navegador y cada 3 minutos, el repositorio público [`platanus-hack/platanus-hack-26-cl-team-5`](https://github.com/platanus-hack/platanus-hack-26-cl-team-5):

- `estado/TABLERO.md`: semáforo, hito vigente y siguiente tarea de cada computador.
- `estado/producto.md`, `estado/amortizacion.md` y `estado/seguimiento.md`: en curso, bloqueos, pedidos, entrenamientos y últimos hechos.
- `WORKPLAN.md`: las tareas P-xx, A-xx y S-xx con su hora y duración, en una línea de tiempo. Una tarea queda «atrasada» cuando lleva el doble de su duración (regla de corte del plan).
- Los últimos commits, con el computador que los hizo.

No escribe nada: la fuente sigue siendo el repositorio del equipo. Para cambiar lo que se ve, se edita `estado/` como siempre.
